# Plan Git — Semana 05

## Repositorio

Repositorio personal del curso.

## Rama base

developer

## Rama de trabajo

feature/week-05-api-integration

## Objetivo de la rama

Documentar la evolución del Dashboard de ocupación hospitalaria hacia una arquitectura cliente-servidor con API REST.

## Cambios incluidos

La rama contiene:

- contrato de API REST;
- diseño cliente-servidor;
- análisis de responsabilidades;
- propiedad de datos;
- seguridad;
- resiliencia;
- observabilidad;
- consistencia;
- análisis de una posible separación como microservicio;
- plan de migración;
- diagramas arquitectónicos.

## Flujo de trabajo

El trabajo se realiza siguiendo este flujo:

developer
→ feature/week-05-api-integration
→ Pull Request
→ developer

## Integración

La rama feature/week-05-api-integration debe integrarse mediante Pull Request hacia developer.

No se realiza integración directa hacia main para esta actividad.

docs/semana-05/

El Pull Request debe mostrar únicamente los cambios correspondientes a la Semana 5 y mantener el historial separado de las semanas anteriores.
