# Semana 09 — Evaluación del diseño, usabilidad y accesibilidad

## Módulo
Dashboard de ocupación hospitalaria.

## Flujo evaluado
Consolidación y consulta de ocupación por sala y estado de cama.

## Objetivo
Evaluar el flujo UX diseñado en la Semana 08 mediante heurísticas de usabilidad y criterios WCAG 2.2, con énfasis en teclado, foco, contraste, etiquetas, mensajes y prevención de errores.

La evaluación prioriza el impacto sobre:

- ocupación;
- salas;
- estados de cama;
- indicadores;
- actualización;
- procedencia de datos.

## Entregables

- Checklist de usabilidad y accesibilidad completado.
- Evidencia de 8 hallazgos.
- Backlog priorizado.
- Corrección propuesta para cada hallazgo.
- Criterio verificable para cada corrección.
- Referencias de WCAG 2.2 y heurísticas de Nielsen.

## Criterio de evaluación

Los hallazgos se documentan como observaciones del diseño disponible. Cuando un comportamiento no puede comprobarse en un wireframe estático, se registra como **no especificado / pendiente de verificación**, en lugar de afirmar que la implementación falla.

## Prioridades

- **P1 — Alta:** puede impedir o dificultar significativamente la consulta de ocupación o el acceso a información crítica.
- **P2 — Media:** afecta comprensión, consistencia o accesibilidad, pero existe una ruta alternativa.
- **P3 — Baja:** mejora de calidad y claridad sin bloquear el flujo principal.
